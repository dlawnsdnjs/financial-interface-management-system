# FIMS 통합 인터페이스 관리 사용설명서

## 1. 개요
FIMS(Financial Interface Management System)는 금융권의 다양한 인터페이스(BATCH, REST, SOAP, MQ, File 등)를 통합 관리하고 자동화하는 플랫폼입니다.

## 2. 주요 기능
- **다양한 프로토콜 지원**: BATCH, REST, SOAP, MQ, FTP 등 다수의 통신 규격 처리.
- **통합 관리 콘솔**: 모든 인터페이스의 등록, 수정, 실행, 일괄 처리를 단일 화면에서 수행.
- **실시간 모니터링**: 인터페이스별 실행 로그, 통계 및 오류 추적.
- **장애 복구**: 실패한 인터페이스에 대한 재처리(Retry) 및 알림 서비스.

## 3. 작업 절차 (How to use)

### 3.1. 인터페이스 등록
1. 메뉴에서 지원하는 프로토콜 유형(BATCH, REST, SOAP, MQ 등)을 선택합니다.
2. 각 프로토콜별 설정 정보(Endpoint URL, Host, Job Name 등)를 입력합니다.
3. 알림 채널 사용 설정 및 필수 추가 정보를 입력하고 저장합니다.

### 3.2. 인터페이스 실행
1. 인터페이스 리스트에서 실행할 항목을 선택합니다.
2. '실행' 버튼을 클릭하여 작업을 트리거합니다.
3. 상세 로그 화면을 통해 프로토콜별 실행 결과를 확인합니다.

### 3.3. 일괄 실행
1. 다수의 인터페이스를 선택하여 '일괄 실행' 기능을 통해 순차적 또는 병렬 작업을 수행합니다.

## 4. 장애 대응
- **오류 확인**: 인터페이스별 실행 로그에서 `MessageLog` 및 상세 응답 데이터를 확인합니다.
- **재처리**: 실패한 로그에 대해 '재처리' 기능을 사용하여 운영 환경에서 즉시 복구 작업을 수행합니다.
