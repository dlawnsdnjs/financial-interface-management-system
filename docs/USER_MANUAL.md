# FIMS 배치 작업 및 인터페이스 사용설명서

## 1. 개요
FIMS(Financial Interface Management System)의 BATCH 프로토콜은 대량의 정산 데이터를 CSV 파일로부터 읽어 DB에 적재하는 업무를 자동화합니다.

## 2. 주요 기능
- **Spring Batch 기반 처리**: 대용량 데이터 처리(Chunk 단위) 및 예외 복구(Retry/Skip) 지원.
- **동적 파라미터 로딩**: 설정 테이블(`TB_BATCH_CONFIG`)을 통해 실행 경로 및 패턴 동적 적용.
- **조건부 입력**: 알림 채널 선택에 따른 동적 필드 표시 (`DynamicForm` 고도화).
- **일괄 실행**: 여러 인터페이스를 선택하여 한 번에 배치 실행.

## 3. 작업 절차 (How to use)

### 3.1. 인터페이스 등록
1. 메뉴에서 BATCH 프로토콜 선택.
2. Job Name 및 정산 관련 경로(input/output path) 설정.
3. 실패 시 알림 채널을 사용할 경우, '알림 사용'을 Y로 설정 후 채널 선택(Email/Slack/SMS).
4. 채널별 필요한 추가 정보(이메일, 웹훅 URL 등)를 입력하고 저장.

### 3.2. 배치 실행
1. 등록된 인터페이스 리스트에서 '실행' 버튼 클릭.
2. 실행 파라미터 창에서 `Target Date`(기본값: 오늘) 및 `Dry Run` 여부 설정.
3. 실행 클릭 후 모니터링 로그를 통해 결과 확인.

### 3.3. 일괄 실행
1. 리스트 상단 체크박스를 활용하여 대상 인터페이스 다수 선택.
2. 우측 상단 '일괄 실행' 버튼 클릭.
3. 시스템이 각 인터페이스의 배치 잡을 순차적으로 실행.

## 4. 장애 대응
- **오류 발생 시**: 인터페이스 상세 로그 화면에서 `MessageLog`를 확인하십시오.
- **재실행**: 실패한 로그에 대해 '재처리' 버튼을 통해 즉시 재시도 가능합니다.
